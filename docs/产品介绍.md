## 二、目标用户

| 用户类型 | 诉求 |
|----------|------|
| 内容创作者 / 短视频创作者 | 快速产出高质量视频,降低制作门槛 |
| 社交媒体运营与营销人员 | 批量、快速生成营销素材 |
| 非专业设计师 / 普通用户 | 无需剪辑技能,通过文字提示即可生成视频 |
| 中小团队 / 专业工作室 | 无限生成、超高清、商业授权、API 接入等专业能力 |

**核心价值:** 让"想法"直接变成"成片",把专业级视频创作能力普惠给每一个人。

## 三、核心卖点

1. **文生视频(AI 驱动)** —— 通过简单文本提示词,数秒内生成电影级、工作室级质量的视频。
2. **全平台覆盖** —— Web / Windows / macOS / Linux / iOS / Android,一处创作、随处使用。
3. **快速出片(关键指标)**
   - **4K** 超高清分辨率
   - **10s** 出片速度
   - **4** 种风格可选
   - **∞** 无限创意可能
4. **灵活参数控制** —— 支持提示词、风格(Style)、画面比例(Ratio)、时长(Duration)等参数调节。
5. **分级订阅体系** —— Free / Pro / Studio 三档套餐(详见下文)。
6. **作品库与灵感社区** —— `Library` 作品库(网格 + 筛选)、`Inspiration` 灵感页。
7. **国际化与主题切换** —— 中英双语、深色/浅色主题持久化。

## 五、视觉风格

### 设计主题:电影胶片 / 影院美学(Filmic)

面向欧美 to C 市场,刻意避开行业泛滥的"AI 科技蓝",追求"premium & filmic"的高级电影质感,塑造"一间数字电影工作室"的国际化品牌气质。

### 色彩系统

| 角色 | 值 |
|------|-----|
| 主色 | 接近黑的炭灰"影院"色 `hsl(240 10% 12%)` |
| 强调色 | 暖琥珀色 `hsl(36 82% 55%)`(`--accent-soft` 与 `--accent-warm` 同值) |
| 背景(深色) | `hsl(240 8% 4%)` |

支持深色 / 浅色双模式,默认深色,通过语义化 Token 切换;深色模式下强调色保持不变,仅主色反转为粉笔白 `hsl(240 8% 95%)`。

### 字体体系(英文优先排版)

整体遵循欧美产品的 English-first 排版:正文与界面以英文为主、小字号标签大量采用 `uppercase` + 宽松字距,营造干净、克制的产品气质。

| 用途 | 字体 |
|------|------|
| 展示标题 | 衬线体(`Georgia` / `Times New Roman`,回退到系统 serif),海报式大字,`--font-display` |
| 正文 | **Inter**(经 `next/font` 注入),回退系统 sans 栈,现代、中性的 to C 产品质感 |
| 时间码 / 元数据 | 等宽字体(`ui-monospace` / `SFMono-Regular` / `Menlo` / `Consolas` / `Courier New` 等),表格数字(`tabular-nums`) |

### 电影工艺签名元素

- Letterbox 黑边
- 胶片颗粒感(film grain, SVG 噪点纹理)
- 时间码(timecode,等宽表格数字)
- REC 录制点(闪烁的琥珀色指示灯)

### 生成预览:"胶片显影"隐喻

生成预览被设计为胶片冲洗/显影过程:深色"显影液"随进度向上攀升、颗粒细微闪烁、前缘一条克制的暖色"显影液线"。

### 动效

**全局动效**漂浮(float)、淡入(fade-in)、微光(shimmer)、REC 脉冲(rec-pulse)、滚动跑马灯(ticker);**生成预览专用动效**`idle-float`、`grain-shimmer`、`developer-line`、`idle-breathe`。全部 GPU 加速(仅 transform / opacity)。

### 设计思路

VibeVideo 的视觉语言围绕一个核心命题:**"这不是一个 AI 工具,而是一间数字电影工作室。"** 由此衍生出一套完整的设计逻辑:

**1. 用"电影工艺"替代"科技科幻"**
绝大多数 AI 产品倾向用靛蓝、电光蓝、玻璃拟态、霓虹 HUD 来暗示"高科技"。VibeVideo 刻意反其道而行,借用了电影工业中的真实视觉符号 —— 时间码(timecode)、录制指示灯(REC,`RecBadge` 组件)、黑边(letterbox)、胶片颗粒(film grain) —— 来建立信任感。原因在于:用户真正想买的是"成片质量",而不是"技术参数";电影工艺符号能让"由 AI 生成"这件事显得更可靠、更有手艺感,而非冷冰冰的算法。

**2. 色板:"炭灰 + 暖琥珀"的高级叙事**
- 主色用接近黑的炭灰(`240 10% 12%`),模拟放映厅暗场,让画面内容成为绝对主角,同时规避了纯黑带来的死板;
- 强调色只用一处暖琥珀(`36 82% 55%`),`--accent-soft` 与 `--accent-warm` 同值,它对应真实片场的钨丝灯与"录制中"指示灯,克制地用于图标、高亮、星标与 REC 圆点,形成"黑暗中的一束暖光"的焦点感;
- 深色模式下强调色保持不变,仅主色反转为"粉笔白",确保按钮与徽章在暗底上始终可见。

**3. 英文优先的字体三件套,各司其职**
- **衬线展示体**(`Georgia` / `Times New Roman`,回退到系统 serif)用于海报式大标题,传递"电影海报 / 杂志封面"的编辑感;
- **Inter**(经 `next/font` 注入)承载正文,现代、中性的欧美 to C 产品质感,统一字号与行高;
- **等宽字体**只出现在时间码、评分、品牌 Logo 墙等"元数据"位置,复刻放映设备上的读数,强化技术可信度。

**4. 生成预览:"胶片显影"而非"进度条"**
渲染进度被设计成暗房冲洗的过程:预览画幅在 idle 时呈现深色中性"显影液"底 + 顶部暖色光晕 + 底部暗部,generating 时氛围转为更暖的"化学活跃"态;显影区域用自下而上攀升的渐变(`hsl(36 82% 55% / 0.14)` → `hsl(240 20% 22% / 0.55)`)表现,前缘是一条渐隐的暖色"显影液线"(`developer-line`),颗粒伴随 `grain-shimmer` 细微闪烁,进度百分比用 timecode 字体展示并附 `FRAME {frameIndex} · developing` 副标。它把"等待生成"这件最焦虑的事,转化为一种有仪式感的"见证成像"体验,让用户感觉自己在参与创作,而非干等一个百分比。

**5. 动效服务于"呼吸感"**
所有动效(漂浮、淡入、微光、脉冲、跑马灯)都只作用于 transform / opacity,GPU 加速、零布局抖动。它们的存在是为了让界面"活着"(如 REC 的脉动、颗粒的闪烁),而非炫技,整体节奏克制、有胶片摄影机的呼吸感。
