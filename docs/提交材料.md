## 一、产品定位

| 项目 | 内容 |
|------|------|
| 产品名称 | **VibeVideo** |
| 定位 | AI 视频生成工作室(AI Video Generation Studio) |

### 产品设计理念

**中心思想:将你的创意变成令人惊叹的视频(Turn your imagination into stunning video)。**

VibeVideo 一切设计都围绕一个朴素而坚定的信念展开 —— 创意的价值不应被工具的门槛所束缚。因此产品以「低门槛输入、高质量输出」为设计出发点:

| 设计理念 | 落地体现 |
|------|------|
| **创意优先,而非工具优先** | 以一段文字提示词为唯一起点,把复杂剪辑、参数调优「隐」在幕后,让用户专注于「想表达什么」 |
| **降低门槛,普惠创作** | 面向内容创作者、运营人员、普通用户等非专业人群,无需剪辑技能即可产出电影级成片 |
| **电影级质感,而非技术参数** | 界面用「电影监视器 / 胶片显影」等工艺隐喻替代科技感装饰,让用户信任「成片质量」而非「算法参数」 |
| **全平台无缝** | Web / 桌面 / 移动一处创作、随处使用,创意不受设备限制 |

> 一句话概括:把专业级视频创作能力从「少数人的技能」变成「每个人的表达」,让「想法」直接成为「令人惊叹的视频」。

## 二、核心价值

**一句话:** 让"想法"直接变成"成片",把专业级视频创作能力普惠给每一个人。

1. **文生视频,AI 驱动** —— 通过简单文本提示词,数秒内生成电影级、工作室级质量的视频。
2. **响应式双端** —— 桌面端与移动端体验完整(落地页核心能力);桌面 Electron / 移动 Capacitor 打包为额外实现,超出落地页范围。
3. **快速出片** —— 4K 超高清分辨率、10s 出片速度、无限创意可能。
4. **灵活参数控制** —— 支持提示词、风格(Style)、画面比例(Ratio)、时长(Duration)等参数调节:
   - **风格(4 种):** Cinematic 电影 / Anime 动漫 / Realistic 写实 / Abstract 抽象
   - **比例(3 种):** 16:9 横屏 / 9:16 竖屏 / 1:1 方形
   - **时长(按套餐分级):** 最短 3s,上限 Free 15s / Pro 30s / Studio 60s
5. **分享与发布** —— 生成完成后支持一键复制分享链接、发布作品,快速分发到平台。
6. **分级订阅体系(扩展)** —— Free / Pro / Studio 三档套餐,覆盖从个人到专业工作室的全场景需求。
7. **作品库与灵感社区(扩展)** —— `Library` 作品库(网格 + 筛选)、`Inspiration` 灵感页,沉淀创作与灵感。
8. **国际化与主题切换** —— 中英双语、深色/浅色主题持久化。

## 四、视觉风格

### 设计主题:电影胶片 / 影院美学(Filmic)

面向欧美 to C 市场,刻意避开行业泛滥的"AI 科技蓝 / 电光蓝",追求 **premium & filmic** 的高级电影质感,塑造"一间数字电影工作室"的国际化品牌气质。

### 色彩系统

| 角色 | 值 | 说明 |
|------|-----|------|
| 主色 | `hsl(240 10% 12%)` | 接近黑的炭灰"影院"色 |
| 强调色 | `hsl(36 82% 55%)` | 暖琥珀色(`--accent-soft` 与 `--accent-warm` 同值) |
| 背景(深色) | `hsl(240 8% 4%)` | 默认深色背景 |
| 前景(深色) | `hsl(240 8% 95%)` | 深色模式文字 |

- 支持 **Dark / Light** 双模式,默认深色,通过语义化 Token 切换;
- 深色模式下强调色保持不变,仅主色反转为"粉笔白" `hsl(240 8% 95%)`,保证按钮与徽章在暗底上始终可见。

### 字体体系(英文优先排版)

整体遵循欧美产品的 English-first 排版:正文与界面以英文为主、小字号标签大量采用 `uppercase` + 宽松字距,营造干净、克制的产品气质。

| 用途 | 字体 | 角色 |
|------|------|------|
| 展示标题 | 衬线体(`Georgia` / `Times New Roman`,回退到系统 serif) | 海报式大字标题,`--font-display` |
| 正文 | **Inter**(经 `next/font` 注入),回退系统 sans 栈 | 全文主体,现代、中性的 to C 产品质感 |
| 时间码 / 元数据 | 等宽字体(`ui-monospace` / `SFMono-Regular` / `Menlo` / `Consolas` / `Courier New`) | 复刻放映设备读数,`tabular-nums` |

### 电影工艺签名元素

| 元素 | 说明 |
|------|------|
| Letterbox 黑边 | 电影画幅黑边 |
| Film grain | 胶片颗粒感,SVG 噪点纹理叠加 |
| Timecode | 时间码,等宽表格数字 |
| REC 录制点 | 闪烁的琥珀色录制指示灯 |

### 生成预览:"胶片显影"隐喻

渲染进度被设计为暗房冲洗过程:深色"显影液"随进度自下而上攀升、颗粒细微闪烁、前缘一条克制的暖色"显影液线",进度百分比以 timecode 字体展示。

### 动效

- **全局动效:** float、fade-in、shimmer、rec-pulse、ticker
- **生成预览专用动效:** idle-float、grain-shimmer、developer-line、idle-breathe
- 全部 GPU 加速(仅使用 transform / opacity),零布局抖动。

## 五、设计思路

VibeVideo 的视觉语言围绕一个核心命题:**"这不是一个 AI 工具,而是一间数字电影工作室。"** 由此衍生出五条设计原则,整体向欧美 to C 软件的成熟审美对齐:

### 原则一:用"电影工艺"替代"科技科幻"

主流 AI 产品习惯用靛蓝、电光蓝、玻璃拟态、霓虹 HUD 来暗示"高科技"。VibeVideo 刻意反其道而行,借用电影工业中真实存在的视觉符号 —— 时间码(timecode)、录制指示灯(REC)、画幅黑边(letterbox)、胶片颗粒(film grain)—— 来建立信任感。

具体而言,刻意回避市面 AI 产品的「模板脸」,转而用一组「反 AI 化」的克制语言:

| 常见 AI 产品的「模板脸」 | VibeVideo 的去 AI 化处理 |
|------|------|
| 电光蓝 / 靛蓝渐变 | 炭灰 + 暖琥珀,全局仅一处暖色强调 |
| 玻璃拟态(backdrop-blur + 半透明白) | 实底「表面」卡片 + 1px 细边框,不做磨砂玻璃堆叠 |
| 大圆角卡片堆叠(rounded-xl / 2xl) | 收敛为小圆角/直角(`rounded-sm`、`rounded-none`),向剪辑台、编辑工作台的方正感靠拢 |
| 发光描边 / 霓虹 HUD | 用真实电影符号(letterbox、timecode、REC、胶片颗粒)替代科技感装饰 |
| 夸张阴影 / 悬浮层次 | 阴影克制甚至省略,层级靠边框与色阶而非投影区分 |
| 大面积渐变色块 | 仅保留 `.bg-brand-gradient` 一处炭灰主按钮渐变,其余以纯色为主 |

> **设计理由:** 越「像 AI 模板」越廉价,越「像真实软件 / 工具」越可信。用户购买的是"成片质量",而非"技术参数"。电影工艺符号让"AI 生成"这件事显得更有手艺感、更可靠,同时天然区隔于市面上千篇一律的 AI 卡片风,形成独特的品牌识别 —— 去 AI 化的本质,是把界面从「算法生成器」拽回「专业创作工具」。

### 原则二:色板"炭灰 + 暖琥珀"的高级叙事

- **主色(炭灰 `240 10% 12%`)** 模拟放映厅暗场,让画面内容成为绝对主角,同时规避纯黑的死板感;
- **强调色(暖琥珀 `36 82% 55%`)** 全站只此一处暖色,对应真实片场的钨丝灯与"录制中"指示灯,克制地用于图标、高亮、星标与 REC 圆点,营造"黑暗中的一束暖光"的焦点;
- **深色模式下强调色保持不变,仅主色反转为"粉笔白"**,保证按钮 / 徽章在暗底上始终可见。

### 原则三:英文优先的字体三件套,各司其职

| 字体 | 职责 | 情绪 |
|------|------|------|
| 衬线展示体 | 海报式大标题 | 电影海报 / 杂志封面的编辑感 |
| Inter(正文) | 全文主体 | 现代、中性的欧美 to C 产品质感,统一字号与行高 |
| 等宽字体 | 时间码、评分、品牌 Logo 墙等元数据 | 复刻放映设备读数,强化技术可信度 |

### 原则四:生成预览用"胶片显影"隐喻进度

渲染进度被设计为暗房冲洗过程:显影区域用自下而上攀升的渐变表现,前缘是渐隐的暖色"显影液线",颗粒伴随闪烁,进度以 timecode 字体展示并附 `FRAME {frameIndex} · developing` 副标。这把"等待生成"这一最焦虑的环节,转化为一种有仪式感的"见证成像"体验,让用户感觉自己在参与创作,而非干等一个百分比数字。

### 原则五:动效服务于"呼吸感"

所有动效只作用于 transform / opacity,GPU 加速、零布局抖动。其存在是为了让界面"活着"(REC 脉动、颗粒闪烁),而非炫技,整体节奏克制,传递胶片摄影机的呼吸感。

## 七、本人对 AI 生成结果所做的修改

本节不重复「五、设计思路」里的设计理由,只记录**我在拿到 CodeBuddy 生成代码之后,实际动手改了什么、改成了什么样**。整体上,CodeBuddy 的初始产物带有两类问题:一是市面 AI 产品的「模板脸」(多层大圆角卡片堆叠、电光蓝渐变);二是偏向「通用 / 中性」,缺少面向欧美 to C 市场的产品化表达。我沿两个方向做了逐项改写:

### 方向一:收敛视觉语言(反 AI 化)

| AI 生成的初始代码 | 我改写后的实现 |
|------|------|
| 多层大圆角卡片堆叠(`rounded-xl` / `2xl`),靠卡片叠放与投影堆出层次 | 单一「监视器」容器(`rounded-md` + 1px 细边框 + 实底),层级靠边框与色阶而非卡片堆叠 |
| 大面积电光蓝 / 靛蓝渐变背景铺满预览区 | 纯黑放映画幅 + letterbox 上下黑边,画面内容成为绝对主角 |
| 通用圆形 / 圆角播放控件 | 直角播放按钮(`rounded-none` + `bg-white/20 backdrop-blur-sm`),预览主体仅 `rounded-sm` 小圆角 |
| 高饱和科技渐变进度展示 | 仅生成进度时出现克制暖色「显影液」渐变,呼应暗房冲洗隐喻 |
| 无电影工业元素 | 顶部 chrome 条(MonitorPlay 图标 + timecode + 状态 Badge)、成片叠加胶片颗粒 |

### 方向二:补齐产品化与信任表达(欧美 to C)

| AI 生成的初始代码 | 我改写后的实现 |
|------|------|
| 中文默认文案 / 全站统一字体 | 英文优先排版:正文用 Inter(`next/font` 注入),展示标题用衬线体(`Georgia` / Times),元数据用等宽字体,三者各司其职 |
| 普通徽章 / 标签 | 小字号 `uppercase` + 宽松字距(`tracking-[0.2em]`)的「板场标记」式标签,复刻欧美产品常见的克制标签气质 |
| 数据只是普通文本 | 数据条(`4K` / `10s` / `4` / `∞`)改用等宽 `timecode` 字体 + `tabular-nums`,复刻放映设备读数,强化技术可信度 |
| 无社会证明元素 | 补充评分徽章(五颗星 + 分值,对齐 JSON-LD 结构化数据)与客户 Logo 墙(`NOVA` / `LUMEN` / `ATLAS` 等可识别品牌名),建立欧美 to C 场景下的信任信号 |
| 评价文案扁平化 | 用户评价改为「杂志式」pull-quote:衬线体大引号 + 非对称网格,并刻意保留中英双语真实用户口吻,不做 i18n 翻译,呼应国际化社区 |
| 缺少 SEO / 分享元信息 | 补齐 Open Graph、结构化数据(评分)、sitemap、robots、manifest 等面向欧美市场的可检索与社交分享配置 |

> **协作方式:** 代码由 CodeBuddy 生成初稿,我再按上述两个方向逐项改写 —— 一是「反 AI 化」,把界面从「算法生成器」拽回「专业创作工具」;二是「欧美 to C 化」,补齐英文优先排版、社会证明、SEO 与信任体系,最终形成与产品定位一致的国际化电影胶片风格。

## 八、网页 SEO

项目从工程层面落地了完整的 SEO 与社交分享能力,全部基于 Next.js App Router 的 `Metadata` 体系与 `app` 目录下的静态路由文件实现:

### 站点级元信息(`src/app/layout.tsx`)

| 项 | 实现 |
|------|------|
| 元数据基址 | `metadataBase: new URL("https://vibevideo.app")`,保证相对路径正确解析为绝对 URL |
| 标题体系 | 默认标题 `VibeVideo — AI Video Generation Studio` + 模板 `%s — VibeVideo` |
| 图标 | `favicon.ico` + 192×192 / 512×512 PNG + Apple touch icon |
| 描述 / 关键词 | 英文为主的 description 与 keywords(含 `AI video generator`、`text to video`、`文生视频` 等中英双语词) |
| 结构化数据 | Open Graph(`type: website`、1200×630 `og-image.png`、`locale: en_US` / `alternateLocale: zh_CN`)+ Twitter Card(`summary_large_image`、`@vibevideo`) |
| 多语言声明 | `alternates.canonical: "/"` + `languages`(`en` / `zh` / `x-default`) |
| 抓取指令 | `robots`(全局 `index` / `follow`,GoogleBot 允许大图预览与完整摘要) |
| 视口与主题 | `viewport`:`themeColor: #0a0a0b` + `colorScheme: dark`,与暗色电影胶片风格一致 |

### 路由级元信息

- `src/lib/seo.ts` 提供 `buildMetadata()` 工厂,统一封装 `canonical` + `openGraph` 样板,并支持 `index: false` 关闭索引;
- 各子页面 `layout.tsx` 通过 `buildMetadata` 或手写 `metadata` 逐页配置:

| 路由 | 配置方式 | 说明 |
|------|------|------|
| `/generate/` | 手写 `metadata` | 独立 title(`AI Video Generator`)、canonical、openGraph |
| `/pricing/`、`/library/`、`/inspiration/`、`/profile/` | `buildMetadata()` | 统一 canonical + openGraph,并各配 `ogDescription` |
| `/login/` | `buildMetadata({ index: false })` | 关闭索引,`robots: noindex, nofollow` |

### 搜索引擎接入文件

| 文件 | 实现 |
|------|------|
| `src/app/sitemap.ts` | 站点地图,收录首页 `/`、`/generate/`、`/library/`、`/pricing/`,含 `lastModified`、`changeFrequency`、`priority`(首页 1.0、generate 0.9、library 0.8),首页声明 `en` / `zh` / `x-default` 多语言 alternates |
| `src/app/robots.ts` | `userAgent: *` 全局允许,`disallow` 排除 `/generate`、`/login`,并指向 `sitemap.xml` 与 host |
| `src/app/manifest.ts` | PWA 清单:应用名、192×192 / 512×512 图标、主题色 `#0a0a0b`、`display: standalone`,支持安装到桌面与移动端 |

> **设计意图:** SEO 不是「贴关键词」,而是把品牌主张(「将创意变成令人惊叹的视频」)与可检索、可分享的工程能力对齐 —— 既让搜索引擎理解产品,也让社交分享卡片成为第一眼的「电影海报」。
